# Studyspace Orbit

A school planner that runs entirely in the browser: timetable, homework diary, grades by quarter, goals,
exams, flashcards and a focus timer.

Everything you enter is stored in your own browser on your own device. Nothing is sent to a server, and this
repository holds only the app's code.

Open the site, then use your browser's "Add to Home Screen" / "Install" to keep it like an app. It works offline
after the first visit.
